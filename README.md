# 🚀 SlackPilot

### Your productivity co-pilot inside Slack.

SlackPilot is a Slack bot I built to make Slack a little more useful.

The idea is simple: instead of constantly switching between Slack, a notes app, a task manager, reminders, and an AI tool, SlackPilot puts some of those things directly inside Slack.

You can create tasks, save information, set reminders, summarize conversations with AI, earn XP, and even get a random cat fact when you need a break.

---
